📖 How To Use NetPulse Pro
01
Setup & Installation
①Ensure you have PHP 8.0+ installed (XAMPP, Laragon, MAMP, or server)
②Place netpulse_full.php in your web server root folder
③Open a browser and visit the URL for your server
# XAMPP (Windows) C:\xampp\htdocs\netpulse_full.php http://localhost/netpulse_full.php # Laragon (Windows) C:\laragon\www\netpulse_full.php http://localhost/netpulse_full.php # Built-in PHP server (any OS) php -S 0.0.0.0:8080 http://localhost:8080/netpulse_full.php # Linux / macOS Apache /var/www/html/netpulse_full.php http://localhost/netpulse_full.php
✅ No database required. No composer install. Drop the single PHP file and open it.
02
Monitor WiFi
①Connect your device to any WiFi network
②Open the dashboard — it auto-detects WiFi via Network Information API
③The Connection Banner will show WiFi with signal strength bars
④Live ping and speed are measured continuously. You can also type speed in the console to force a measurement
// What the dashboard detects for WiFi: Connection Type → wifi Effective Speed → 4g / 3g / 2g Downlink → estimated Mbps RTT → round-trip ms Save-Data → on/off (data saver)
⚠️ WiFi signal strength (dBm) requires OS-level tools. The browser API gives speed class, not raw signal. Use the console scan command for more detail.
03
Monitor Ethernet
①Plug in your RJ-45 Ethernet cable to router or switch
②Open the dashboard — Ethernet detected as connection type ethernet
③PHP reads /proc/net/dev on Linux to show real interface bytes (eth0, ens3, etc.)
④On Windows, use the console command interfaces to see adapter details
# Linux: check interface stats live cat /proc/net/dev ip -s link show eth0 # Windows PowerShell Get-NetAdapter | Select Name, Status, LinkSpeed # macOS networksetup -listallhardwareports ifconfig en0
✅ Ethernet connections usually show the lowest latency. Expected ping < 5ms on LAN, < 50ms on WAN.
04
Monitor Mobile / Hotspot
①Open your phone's hotspot (Settings → Hotspot) or use mobile data on a phone/tablet
②Connect your laptop or PC to the hotspot — or open this page directly on the mobile device
③Connection type shows cellular — the dashboard detects 2G/3G/4G/5G automatically
④Data saver mode is detected and displayed in the banner
// Cellular effective types detected: slow-2g → < 50 kbps (2G GPRS) 2g → ~250 kbps (EDGE) 3g → ~750 kbps (HSPA) 4g → ~4+ Mbps (LTE / 5G NR) // On the phone itself, open: http://<your-server-ip>:8080/netpulse_full.php
⚠️ The Network Information API is not supported in Firefox or Safari. Use Chrome, Edge, or Samsung Browser for full detection.
05
Console Commands
ping → Measure live latency speed → Estimate download speed interfaces → List detected network interfaces dns → Show DNS servers in use scan → Full environment scan info → Show server PHP info type → Show current connection type ip → Show public IP details clear → Clear console output help → Show all commands
💡 Type any command into the console at the bottom of the main panel and press Enter or click RUN.
06
Tips & Troubleshooting
💡Connection not detected? Use Chrome/Edge — Firefox and Safari have limited Network Information API support
💡PHP interfaces empty? On Windows, PHP may not return network interfaces. The JS WebRTC fallback still detects your IPs
💡Speed test inaccurate? The browser estimate uses available hints. For precise results, use the speed console command which fetches a test payload
💡Monitor from phone? Run php -S 0.0.0.0:8080 on your PC, then open http://<PC-IP>:8080/netpulse_full.php on your phone
⚠️ Some speed/ping features require internet access to reach test endpoints (Cloudflare 1.1.1.1, etc.).
